# Little Scenes

A browser animation studio for five vector characters, event scenes and projection mapping.

- [Open studio](https://mircoaurelio.github.io/little-scenes/)
- [Curated collection](https://mircoaurelio.github.io/little-scenes/Collection%20Library.html)
- [Absurd scenes](https://mircoaurelio.github.io/little-scenes/Absurd%20Scenes.html)

Includes rounded vector artwork, individual animation switches, random sequencing, size/color waves, four-corner projector alignment, SVG/PNG export and offline playback downloads. Processing and saved settings stay in the browser.

This repository contains only the files served by the published app.

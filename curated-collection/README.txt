COLLECTION 01 — ENSEMBLE STUDIES
Six looping scenes. Thirty individual character roles.

Open Collection Library.html for animated playback, pause/scrub/speed controls,
and individual role inspection. SVG frame and scene-preset downloads work offline.
Use Open saved project in Little Scenes Studio.html to load any presets/*.json.
In the main studio, Add collection enables all six while keeping existing choices.

manifest.json lists each scene, five named roles, four timing beats, normalized
settings and the paths of all reference SVG samples.
presets/: six complete scenes and thirty individual-role projects.
frames/: three sample moments (1.5, 4.5, 8.5 seconds) for each scene and each role.
The loops last 12 seconds at movement speed 1.0. Reference cadence is 24 fps.

Original armless vector characters, original editable palette, black background.
Characters remain above the standing baseline. Props animate independently.
The collection is an artistic animation reference library.
